## 🚀 What is Invoice Ready?

A **self-hosted invoice and quotation management system** built for freelancers, agencies, and small teams. Combines invoice CRUD, quotation workflows, payment tracking, and revenue analytics with **automated PDF generation** and **multi-channel delivery** — all in a type-safe monorepo.

---

## ✨ Key Features

| Feature | Description |
|---------|-------------|
| 📄 **Invoice Management** | CRUD with auto-overdue detection and status lifecycle (DRAFT → PAID) |
| 📋 **Quotation Workflow** | Approval flow, expiry tracking, one-click conversion to invoice |
| 📧 **PDF & Email Delivery** | PDFKit generation with 30-min cache + Nodemailer dispatch |
| 💬 **WhatsApp Alerts** | Due/overdue reminders via WhatsApp Graph API |
| ⏰ **Smart Scheduler** | Daily cron checks with automated notifications |
| 📊 **Revenue Dashboard** | ApexCharts visualization for revenue, status, payment methods |
| 🔐 **Role-Based Access** | JWT auth with Admin/User roles, HTTP-only cookies |
| 🔍 **Command Palette** | cmdk-powered search (Ctrl+K) across all 17+ routes |
| ✅ **Type-Safe** | Shared Zod schemas across frontend & backend |
